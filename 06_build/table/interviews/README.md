# Sample interviews (invented)

Three short interview transcripts, written for this workshop. They are invented: no real person said these words. They stand in for the kind of qualitative material a researcher codes by hand: interviews, open-ended survey answers, focus-group notes, field notes. Use them to see the table recipe code text with quotes before you point it at your own (and only at material you are free to send to the model service; never at data covered by an IRB protocol).
