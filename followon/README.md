# Follow-on: going further on your own

Nothing here is for the workshop day. Each item is a real exercise with its own page, in roughly increasing order of effort. Start with continue.md, which is the one you need on Thursday morning.

- continue.md: when the workshop key expires and how to point the same code at another endpoint, including Cimarron, a hosted model, or a model on your laptop.
- own-record.md: write your own Record from scratch for a different kind of document.
- write-the-loop/: write the tool-calling loop yourself from a fill-in-the-blanks version, then compare with agent.py.
- concurrency.md: run the folder script over hundreds of documents at once.
- embeddings.md: replace keyword search with meaning-based search.
- public-api.md: look up references through a public API as a tool.
- frameworks.md: the same agent in a popular framework, and what you give up.
- openclaw/: a full personal agent program, for comparison with the forty-line loop.
