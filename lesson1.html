Lesson 1: What Is a Buffer?

← Home / Lesson 1

1.1 Definition & Core Idea

A buffer is a solution that resists changes in pH when small amounts of strong acid or strong base are added. It does this by containing both a weak acid and its conjugate base (or a weak base and its conjugate acid) in comparable amounts.

Key Components

  • Weak acid (HA) — partially dissociates: HA ⇌ H⁺ + A⁻
  • Conjugate base (A⁻) — accepts H⁺ to reform HA
  • Together: a conjugate acid–base pair

1.2 How a Buffer Works: The Seesaw Mechanism

When you add a small amount of strong acid (H⁺) or strong base (OH⁻), the buffer components react to neutralize it:

Added strong acid (H⁺):

H⁺ + A⁻ → HA

The conjugate base (A⁻) "mops up" the added H⁺, converting it to the weak acid HA. The pH barely changes.

Added strong base (OH⁻):

OH⁻ + HA → A⁻ + H₂O

The weak acid (HA) donates H⁺ to neutralize OH⁻, forming water and the conjugate base A⁻. Again, pH barely changes.

Think of it as a seesaw: the weak acid and conjugate base shift back and forth, absorbing added H⁺ or OH⁻ while keeping the ratio [A⁻]/[HA] — and thus the pH — relatively stable.

Rule of thumb: A buffer works best within ±1 pH unit of its pKₐ. Outside this range, one component is too depleted to neutralize added acid/base effectively.

1.4 What a Buffer Is NOT

  • Not a strong acid + its conjugate base (e.g., HCl/Cl⁻) — strong acids fully dissociate, no equilibrium to shift
  • Not a single weak acid or weak base alone — needs both components present
  • Not infinitely resistant — has a buffer capacity (Lesson 3)
