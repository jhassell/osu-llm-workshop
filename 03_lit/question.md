Research question: How much do cover crops increase soil organic carbon, and why do the amounts reported in different studies differ?

Sources: the three papers in corpus/papers/. Read a paper with `python 03_lit/pages.py <file>` (or one page: `python 03_lit/pages.py <file> <page>`). Quote only from that text, word for word, with its page number. Keep any script you write in results/, not among the tools in 03_lit/. For a value in a table, the quote is the table's line exactly as pages.py prints it.

1. Find every value these papers report for the effect of cover crops on soil organic carbon: a stock, a concentration, a percentage or a rate. Put each in results/values.csv, one row per value, with these columns: source, page, quote, value, unit, conditions, value_std, unit_std, conversion, status, note. Write it with Python's csv module, so that a field containing a comma is quoted and every row has exactly these eleven fields; page is a whole number. In conditions, record what the value depends on (site, soil depth, years of cover cropping, what it is compared with, method). Choose one standard unit, fill in value_std and the conversion you used (arithmetic in v, such as v / 8) where a value can be converted, and leave value_std and conversion both empty where converting would mean inventing something (a value that cannot be converted is not a failure, so never flag a row for that).

2. Run `python 03_lit/check_values.py` after every change to the file. When a row fails, reread that page and fix the row. Set status to flagged only when a row cannot be fixed, and say in note which check failed and why it cannot be fixed. Never delete a row to make the check pass.

3. Form a hypothesis for why the values differ (for example depth, duration, climate, cropping system, what the baseline was, or units that are not comparable). Test it against the rows: does it explain the spread, or not? Revise it if it does not. If these three papers cannot settle it, search for more with `python 03_lit/lit.py "<query>"` (at most three searches: the whole room shares one search allowance) and use a paper's abstract as a source (source doi:<DOI>, page 0), with the same check. Run at least one search. The check writes results/sources.bib for every searched paper you use, with its DOI checked.

4. Stop when another search or another reading would not change your answer, and say why you stopped. Write results/answer.md: the range of values that can fairly be compared, your explanation and the rows that support it, the hypotheses you tested and rejected, and what is still unexplained. Every number in answer.md must be a row of values.csv that passes the check or is flagged.
