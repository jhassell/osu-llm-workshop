# A saved evidence table

What `python 03_lit/pdfask.py corpus/papers/*.pdf` produced on November 6, 2026, with NVIDIA Nemotron 3 Ultra: `table.jsonl` (one row per paper), `evidence-table.html` (download it and open it on your laptop to read each value beside its quote), and `papers/` (the text the model read, page by page).
