# The four lines, written before the first prompt

Observational unit: one county in one harvest year. (In the file a row is one statistic for a county-year, so the data must be reshaped first.)

Outcome: winter wheat yield, in bushels per harvested acre.

Comparison: harvest year, 2000 to 2025: has yield gone up?

One plausible confounder: which counties are published. NASS published 68 to 75 counties a year until 2007 and 38 to 55 from 2008, pooling the rest, so an average over published counties can move because the set of counties changed, not because yields did. (Weather is the other big driver, but it works year by year rather than as a trend.)

What the reference got: a small upward trend once each county is compared with itself, swamped by drought years such as 2014. See reference/report.md and reference/extension.md.
