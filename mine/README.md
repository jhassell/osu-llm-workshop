# mine/

Your own documents go here. Drag PDF, Word or text files from your laptop onto this folder in the file tree, then run:

    python convert.py

Nothing in this folder is ever committed or pushed: it is listed in .gitignore. It does leave the Codespace in one way: when a lab reads a document, its text is sent to the workshop's model endpoint, exactly as the sample documents are. Bring only documents you are free to share with that service. The sample corpus in corpus/ is always enough for every lab, so bringing your own documents is optional.
